Attacks

Every attack below was found in our research and responsibly disclosed to the affected vendors. Each one links to a page explaining how it works, and to the paper that introduced it, where you also find the evaluation, exploits, and CVEs.

PDF Signatures

IEEE S&P 2021 Breaking the Specification: PDF Certification

  • Evil Annotation Attack EAAAnnotations, which certification level P3 allows, overlay the certified content with arbitrary text or images. How the attack works →
  • Sneaky Signature Attack SSASignature fields, which certification level P2 allows, are abused to add arbitrary content to a certified document. How the attack works →

NDSS 2021 Shadow Attacks: Hiding and Replacing Content in Signed PDFs

  • HideContent hidden under an overlay when the document is signed is revealed afterwards by removing the overlay in an incremental update. How the attack works →
  • ReplaceAn incremental update after signing replaces objects such as fonts, which changes how the signed content is displayed. How the attack works →
  • Hide-and-ReplaceA complete shadow document inside the signed file is activated by an appended xref table, exchanging the entire content. How the attack works →

ACM CCS 2019 1 Trillion Dollar Refund: How To Spoof PDF Signatures

  • Universal Signature Forgery USFManipulated signature objects make viewers skip the verification but still report a valid signature. How the attack works →
  • Incremental Saving Attack ISAContent appended by an incremental update after signing is displayed without invalidating the signature. How the attack works →
  • Signature Wrapping Attack SWAA manipulated /ByteRange moves the signed bytes so that unsigned content can be placed in the signed document. How the attack works →

PDF Encryption

ACM CCS 2019 Practical Decryption exFiltration: Breaking PDF Encryption

  • Direct Exfiltration Attack AUnencrypted forms, links, or JavaScript added to an encrypted PDF send its decrypted content to the attacker. How the attack works →
  • CBC Gadgets Attack BCBC malleability turns known plaintext into gadgets that inject exfiltration code into the encrypted content itself. How the attack works →

Insecure Features

NDSS 2021 Processing Dangerous Paths – On Security and Privacy of the Portable Document Format

  • Denial of ServiceInfinite loops and deflate bombs in the document structure make PDF processors hang or exhaust their memory. How the attack works →
  • Information DisclosureURL invocation, form submission, and file access leak document contents, local files, or credentials. How the attack works →
  • Data ManipulationDocuments silently modify form values, write local files, or mask their displayed content. How the attack works →
  • Code ExecutionThe Launch action starts embedded or referenced executables when the document is opened. How the attack works →
